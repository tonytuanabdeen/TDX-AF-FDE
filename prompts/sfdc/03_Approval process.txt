### 1. Approval Process

File: `approvalProcesses/Loan_Application__c.Loan_Application_Approval.approvalProcess-meta.xml`

- Object: Loan_Application__c
- Name: Loan_Application_Approval
- Entry criteria: Status__c = "Pending Approval"
- Approver: user with username `msmith@fdebank.fde` (single approver, no delegation)
- On **approval**: update Status__c to "Approved"
- On **rejection**: update Status__c to "Rejected"
- Rejection reason field: Reject_Reason__c (the approver's comment should populate this field)
- Initial submitter: allow record owner to submit
- Record editability during approval: locked (administrator only)

### 2. Automation: Submit on New → Pending Approval

Create a Record-Triggered Flow (or Apex trigger — choose whichever deploys cleanly to the scratch org) that:

- Triggers when a `Loan_Application__c` record is **created** with `Status__c = 'New'`
- Updates `Status__c` to `'Pending Approval'`
- Submits the record into the `Loan_Application_Approval` approval process

If using a Flow:
File: `flows/Loan_Application_Submit_For_Approval.flow-meta.xml`
- Trigger: Record Created, object Loan_Application__c, condition: Status__c = "New"
- Action: Submit for Approval (use the Submit for Approval core action)

If using an Apex Trigger:
File: `triggers/LoanApplicationApprovalTrigger.trigger`
- `after insert` trigger
- Filter: `trigger.new` records where Status__c = 'New'
- Use `Approval.ProcessSubmitRequest` to submit programmatically
