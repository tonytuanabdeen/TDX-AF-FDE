### 3. Architecture — feature-first


State management: `flutter_riverpod`
Navigation: `go_router` with a ShellRoute for the bottom nav
Local persistence: `shared_preferences`

### 4. Screens

Each screen has an AppBar and branded placeholder content:

- **HomeScreen** — greeting ("Good morning!") + placeholder account balance card with `#C0001E` accent + a "Request a Mortgage" card/button (route: `/mortgage`, wired up in prompt 02)
- **AccountsScreen** — placeholder list of 2–3 mock accounts
- **PaymentsScreen** — placeholder payment form
- **ProfileScreen** — displays the Salesforce Contact ID (see point 5)

Bottom nav icons: Home, Accounts, Payments, Profile.

---

### 5. Salesforce Contact ID

`lib/core/services/salesforce_service.dart`:
- `Future<String?> getContactId()` — reads `shared_preferences` key `sf_contact_id`
- `Future<void> setContactId(String id)` — writes the key
- `Future<void> clearContactId()` — deletes the key

`salesforceContactIdProvider` — `AsyncNotifierProvider<SalesforceContactIdNotifier, String?>` that loads from `shared_preferences` on init and exposes `setContactId` / `clearContactId`.

ProfileScreen: shows the stored ID (or "Not linked"), with an edit icon that opens an `AlertDialog` to update it.
