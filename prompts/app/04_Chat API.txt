### 2. AgentService

`lib/features/mortgage/services/agent_service.dart`

**createSession(String contactId) → Future\<AgentSession\>**

POST `${agentApiBaseUrl}/agents/${agentId}/sessions`

Request body:
```json
{
  "externalSessionKey": "<uuid_v4 generated at runtime>",
  "instanceConfig": { "endpoint": "<SalesforceConfig.instanceUrl>" },
  "featureSupport": "Streaming",
  "streamingCapabilities": { "chunkTypes": ["Text"] },
  "variables": [
    { "name": "$Context.EndUserLanguage", "type": "Text", "value": "en_US" },
    { "name": "salesforceContactId", "type": "Text", "value": "<contactId>" }
  ]
}
```

Note: the variable name is `salesforceContactId` (not `ContactId`) — this must match the agent variable name exactly.

Returns `AgentSession` with `sessionId`. Throws `AgentSessionException` on failure.

---

**sendMessage(String sessionId, String text, int sequenceId) → Future\<String\>**

POST `${agentApiBaseUrl}/sessions/${sessionId}/messages`

Request body:
```json
{
  "message": {
    "sequenceId": <sequenceId>,
    "type": "Text",
    "text": "<text>"
  },
  "variables": []
}
```

Parse reply from `response.messages[].message` where `type == "text"` (case-insensitive). Concatenate multiple text chunks. Throws `AgentMessageException` on non-200.

---

**endSession(String sessionId) → Future\<void\>**

DELETE `${agentApiBaseUrl}/sessions/${sessionId}`

Best-effort — swallow all exceptions silently.

### 4. Providers

`lib/features/mortgage/providers/chat_provider.dart`

- `agentServiceProvider` — `Provider<AgentService>` (reads `salesforceAuthServiceProvider`)
- `agentSessionProvider` — `StateProvider<AgentSession?>`
- `chatMessagesProvider` — `StateNotifierProvider<ChatNotifier, List<ChatMessage>>`

**ChatNotifier**:

- `initSession(String contactId)`:
  - Calls `AgentService.createSession(contactId)`
  - Stores session in `agentSessionProvider`
  - Appends agent greeting from the API response if available, otherwise fallback: "Hi! I'm FrED, FDE Bank's AI Assistant. How can I help you?"

- `sendMessage(String text)`:
  - Appends user bubble immediately
  - Appends a loading bubble (`isLoading: true`)
  - Calls `AgentService.sendMessage(sessionId, text, sequenceId)`
  - Replaces loading bubble with real reply
  - On error: replaces loading bubble with "Sorry, something went wrong. Please try again."
  - Tracks an internal `_sequenceId` counter starting at 1, incremented per message

- `endSession()`:
  - Calls `AgentService.endSession(sessionId)`
  - Resets state and clears `agentSessionProvider`
